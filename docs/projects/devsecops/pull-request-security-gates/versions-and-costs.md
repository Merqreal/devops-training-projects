# Versions, licensing and costs — DEVOPS-005

Sources inspected **2026-11-25**; licensing and feature availability can change. Documentation inspection is not proof of account eligibility, runtime compatibility or a successful integration. Before work, verify the current terms and versioned documentation for your account, region, repository visibility and intended use. Record exact versions and immutable action references, compatible server/client pairs, runner images, build wrappers, dependencies and configuration contracts in your submission. Do not invent pins for inaccessible platforms; document the blocker instead.

| Offering | Starting point and qualification to investigate |
| --- | --- |
| Black Duck SCA | [Black Duck scanning documentation](https://docs.blackduck.com/r/blackduck/2025.4/black-duck-documentation/scanning-your-code.html) describes component scanning, policy and API use, with licensing qualifications. A permanent free offering meeting this assignment is **not established** by that documentation. Verify eligibility and access before relying on it. |
| Coverity | [Coverity Scan](https://scan.coverity.com/) is an open-source service; assess project eligibility, supported languages, access to results and its limits against per-PR automation. Do not assume a commercial platform or trial is free. |
| SonarQube | [SonarQube Server 2025.1 PR analysis](https://docs.sonarsource.com/sonarqube-server/2025.1/analyzing-source-code/pull-request-analysis/introduction) requires Developer Edition or above. [SonarQube Cloud plans](https://docs.sonarsource.com/sonarqube-cloud/administering-sonarcloud/managing-subscription/subscription-plans) describe free and OSS offerings with different conditions; verify PR analysis, limits and eligibility for the chosen organization. Community Build and Cloud are distinct offerings. |

For **each** scanner document license and eligibility; supported languages and build systems; PR analysis and enforcement; API and machine-readable results; public/private restrictions; scan frequency and usage limits; and exact versions and sources. Determine whether final results can be securely retrieved and tied to the relevant commit. If any mandatory capability is unavailable within an eligible free offering, report the blocker and propose an alternative for approval. Never silently substitute a scanner or treat an expiring trial as a permanent solution.

Consult [GitHub required-check troubleshooting](https://docs.github.com/en/pull-requests/how-tos/merge-and-close-pull-requests/troubleshooting-required-status-checks) for current plan, commit and skipped-check behavior, and [GitHub runner security](https://docs.github.com/en/actions/concepts/security/compromised-runners) for the consequences of executing untrusted code. Verify limits and cost for GitHub Actions, scanner hosting, network traffic and any AWS resources before use. If choosing CodeBuild, consult [AWS CodeBuild pricing](https://aws.amazon.com/codebuild/pricing/) and [CodeBuild-hosted GitHub Actions runners](https://docs.aws.amazon.com/codebuild/latest/userguide/action-runner.html); estimate cost and define teardown. Free scanner licenses do not imply free AWS usage. Avoid unexpected charges and do not enable paid subscriptions.
